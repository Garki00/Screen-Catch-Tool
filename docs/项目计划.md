# Screen Capture Tool - 项目计划

## 项目概述

### 项目名称
Screen Capture Tool - 实时屏幕捕获工具

### 项目描述
一个Windows桌面应用程序，能够实时捕获指定窗口/桌面画面，通过桌面端gui和web界面显示。可以打包为exe.

### 核心技术栈
- **开发语言**: Python 3.11+
- **桌面GUI**: PySide6 (Qt 6 for Python)
- **Web服务器**: Flask + Flask-SocketIO
- **前端**: HTML5 + CSS + JavaScript (响应式设计)
- **屏幕捕获**: Windows Graphics Capture (通过 windows-capture 库)
- **图像处理**: HTML5 Canvas API (前端) / Pillow (后端缩略图)
- **实时通信**: WebSocket (Flask-SocketIO)

## 功能需求详细说明

### 1. 核心功能模块

#### 1.1 屏幕捕获逻辑
- **实时捕获**: 按设定间隔(2-10秒，默认5秒)捕获屏幕
- **捕获范围**: 
  - 指定显示器捕获
  - 指定窗口捕获
- **捕获范围内自定义区域裁剪**：在web端裁剪显示选择框范围内的图片（但实际仍然捕获指定显示器或指定窗口全尺寸图片，仅在显示在web端前剪裁）
- **图片缓存管理**:
  - 本地缓存最多20张截图 + 1张正在预览的历史图片
  - 超出限制自动删除最旧的图片
  - 图片格式: jpeg
  - 存储路径: `./cache/screenshots/`

#### 1.2 桌面端界面（主题语言：中文）

- **实时预览窗口**: 显示当前捕获的画面
- **范围选择框**：显示当前web端输出的范围

- **下边栏控制面板**:
    - 开始/停止捕获按钮
    - 捕获范围按钮：
        - 弹出捕获范围选择窗口
        - 窗口选择栏
        - 屏幕选择栏
    - 范围选择按钮: 点击后可以编辑实时预览背景上可拖动的选择框
        
- **右侧边栏最上设置按钮栏**：
    - 点击展开
    - 捕获间隔设置(2-10秒，默认5秒)
    - web端口设置（默认9178，不支持非法端口<1024、>65535，修改端口时若web服务启动则重启）

- **右侧边栏状态指示器**：
    - 捕获状态：(捕获中/已停止)
    - web端是否已启动（未启动/已启动）（已启动显示地址：(eg:127.0.0.1:9178)）

#### 1.3 Web前端界面 (响应式设计，主题语言：中文)
- **主界面元素**:
  - 实时更新的截图展示区域(WebSocket推送)
  - 【下载图片】按钮：下载最新的一张捕获的图片
  - 历史记录展示区域：展示固定高度左右滚动区域展示历史捕获图片，点击后可在下方预览，正在预览的图片暂时不删除。
- 手机端，电脑端，平板端适配

#### 1.4 系统托盘栏
点击桌面端关闭按钮时，应用应最小化至系统托盘：不退出程序、不中断捕获，仅隐藏任务栏图标，并支持从托盘重新唤起主界面。

- **右键点击托盘**： 
    - **捕获状态**：(捕获中/已停止)，点击可以切换状态，用不同图标
    - **退出**：完全退出程序
- **左键点击托盘**：显示桌面端
